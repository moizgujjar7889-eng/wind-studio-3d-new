# Wind Studio 3D — character and cloth upgrade

This version upgrades the asset-free character to a higher-detail, softly
shaded adult female procedural character, improves face/hair silhouettes,
and stabilizes the dress/hair Verlet solver.

The project still uses procedural Three.js geometry. Truly photorealistic
skin/hair/clothing would require licensed external 3D assets/textures (for
example a GLB/GLTF character), which are not included in this ZIP.
